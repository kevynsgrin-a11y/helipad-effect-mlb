This demonstration report uses a heuristic model to combine air density, wind direction, ballpark factors and pitcher stress to produce a Helipad Index for each MLB park. Values range from 0 (very pitcher‑friendly) to 100 (very hitter‑friendly). Letter grades translate the index into simple categories. In a production environment the conditions would be pulled from live weather data and game schedules rather than randomised samples.
